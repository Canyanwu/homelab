# Physical Cisco lab

Hardware: Cisco 2901 router, 2960 layer 2 switch, 3550 layer 3 switch.

## Goal
Practise routing, switching and ACLs on real hardware to support CCNA study.

## Topics covered
- Inter-VLAN routing
- Trunking
- ACLs
- Enterprise switching through the CLI console
